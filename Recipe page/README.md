# Frontend Mentor - Recipe Page Solution

This is my solution to the **Recipe Page** challenge from Frontend Mentor. The project focuses on building a clean, responsive recipe page using semantic HTML and modern CSS techniques while closely matching the provided design.

## 🔗 Links

- **Live Site:** https://lailaharb004-creator.github.io/FrontEnd-Mentor-/Recipe%20page/
- **Solution Repository:** https://github.com/lailaharb004-creator/FrontEnd-Mentor-/tree/main/Recipe%20page

## 🚀 Built With

- Semantic HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries
- Google Fonts
- HTML Tables

## ✨ Features

- Responsive recipe card layout.
- Clean typography using **Young Serif** and **Inter** fonts.
- Recipe image with rounded corners.
- Preparation time section with highlighted styling.
- Ingredients and instructions displayed using semantic lists.
- Nutrition information presented in a structured table.
- Soft color palette matching the design reference.
- Mobile-friendly layout for smaller screen sizes.

## 📚 What I Learned

While building this project, I practiced:

- Structuring content with semantic HTML elements.
- Styling different list types (`ul` and `ol`) for ingredients and instructions.
- Creating reusable card sections with consistent spacing.
- Designing responsive layouts using Flexbox.
- Styling HTML tables for structured data.
- Using media queries to improve the mobile experience.

Example:

```css
body {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
}

.card {
    display: flex;
    flex-direction: column;
    width: 40%;
    padding: 30px;
    border-radius: 20px;
}
```

This helped me better understand how Flexbox can be used to center content and build responsive card layouts.

## 📱 Responsive Design

The layout adapts to different screen sizes:

- **Desktop:** The recipe card is centered with a fixed width for comfortable reading.
- **Mobile:** The card expands to the full width of the screen, making the content easier to read on smaller devices.

## 🛠️ Future Improvements

- Use CSS custom properties (variables) for colors, spacing, and typography.
- Improve accessibility by adding descriptive `alt` text to images.
- Enhance the responsive layout with additional breakpoints.
- Refactor repeated styles into reusable utility classes.
