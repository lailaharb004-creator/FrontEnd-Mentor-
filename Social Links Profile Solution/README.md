# Frontend Mentor - Social Links Profile Solution

This is my solution to the **Social Links Profile** challenge from Frontend Mentor. The project focuses on creating a simple and responsive profile card with social media links while practicing layout structure, Flexbox, styling, and interactive states.

## ✨ Features

- Responsive profile card layout.
- Circular profile image with clean styling.
- Social media buttons with hover effects.
- Accessible focus state using `:focus-visible`.
- Centered card layout using Flexbox.
- Dark theme design matching the original challenge.

## 📚 What I Learned

During this project, I practiced:

- Building reusable UI components using HTML and CSS.
- Creating centered layouts with Flexbox.
- Managing spacing and alignment between elements.
- Styling interactive elements such as links.
- Improving accessibility by adding visible focus states.

Example:

```css
.link:hover {
    color: #c5e653;
}

.link:focus-visible {
    background-color: #a29d99;
}
```

These states improve the user experience by providing visual feedback when interacting with buttons and links.

## 📱 Responsive Design

The component was designed to work across different screen sizes:

- The card automatically adjusts its width using `max-width`.
- Flexible layouts keep the content centered on mobile and desktop.
- Buttons expand to fit the available card width.
