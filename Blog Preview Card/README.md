# Frontend Mentor - Blog Preview Card Component Solution

This is my solution to the **Blog Preview Card Component** challenge from Frontend Mentor. The goal of this project was to create a simple blog article preview card that matches the provided design while practicing card layouts, spacing, typography, and responsive styling.

## 🚀 Built With

- Semantic HTML5
- CSS3
- Flexbox
- Responsive Design
- Box Shadow Styling

## ✨ Features

- Clean blog article preview card design.
- Custom category badge styling.
- Article title and description layout.
- Author section with profile image.
- Responsive card sizing for different screen widths.
- Styled border and shadow effect to match the original design.

## 📚 What I Learned

While building this project, I practiced:

- Creating reusable card components with HTML and CSS.
- Controlling layouts using Flexbox.
- Improving visual hierarchy through typography and spacing.
- Using borders and shadows to recreate modern UI designs.
- Making components responsive using flexible widths.

Example:

```css
.card {
    border-radius: 10px;
    box-shadow: 8px 8px 0 black;
    border: solid 1px black;
}
```

This helped me understand how small visual details can improve the overall look and feel of a component.

## 📱 Responsive Design

The card adapts to different screen sizes:

- Uses flexible widths with `max-width`.
- Keeps the content readable on smaller screens.
- Maintains spacing and alignment across devices.
